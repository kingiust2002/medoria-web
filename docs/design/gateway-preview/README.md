# پیش‌نمایش طراحی گیت‌وی Medoria

دو پیش‌نمایش بازسازی لایه‌دار، با ابعاد **۳۸۴۰×۲۱۶۰**. جای پنج سکو، قاب اتاق و محل لوگو در هر دو نسخه مشترک است؛ نسخهٔ Health نور سرد و نسخهٔ Beauty رنگ مسی دارد.

**Beauty نسخهٔ دوم:** محصولات از ۱۵ عکس مستقلِ سایت‌های رسمی Dior، Chanel، Guerlain، Tom Ford و Hermès مونتاژ شده‌اند. هیچ محصولی از عکس قبلی گیت‌وی بریده نشده است. هر سکو یک دستهٔ جدا دارد؛ تصویرهای بسته‌بندی و لوگوی برندها از منابع اصلی حفظ شده‌اند.

انتخاب‌ها شامل پالت‌های Runway و Soleil Neige تام فورد، قاب نگین‌دار Rouge G گرلن، رژ محدود Rose Épicé هرمس و Dior Addict Lip Glow Oil است. مدل‌ها با توجه به معرفی‌های فعلی برند، شکل بسته‌بندی، ترکیب رنگ و کیفیت عکس انتخاب شده‌اند. [منابع و ابعاد عکس‌های اصلی](beauty-sources.json)
