# پیش‌نمایش طراحی گیت‌وی Medoria

دو پیش‌نمایش بازسازی لایه‌دار، با ابعاد **۳۸۴۰×۲۱۶۰**. جای پنج سکو، قاب اتاق و محل لوگو در هر دو نسخه مشترک است؛ نسخهٔ Health نور سرد و نسخهٔ Beauty رنگ مسی دارد.

محصولات و برندها از همان تصاویر فعلی گیت‌وی حفظ شده‌اند. جزئیات محصولات همچنان به وضوح تصویر مرجع محدود است؛ برای نسخهٔ نهایی با بالاترین کیفیت، عکس مستقل و باکیفیت هر محصول لازم است. این تصاویر برای بررسی طراحی هستند.
